# iyzico Transaction Count Forecasting

## Overview
This project is a time series forecasting project. It predicts the daily total transaction count of merchants for the last 3 months of 2020 using machine learning.

---

## Project Structure
- `PROJE_TRANSACTION_COUNT_FORECASTING.py` - Main Python script for data processing and modeling
- `iyzico_data.csv` - Dataset containing transaction records from 2018 to 2020
- `outputs/` - Folder containing generated data visualization plots

---

## Prerequisites
- Python 3.x
- Libraries:
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn
  - LightGBM
